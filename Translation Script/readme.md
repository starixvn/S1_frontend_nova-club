# Translation Script

This repository contains a script for translating an excel file.

## Prerequisites

Before running the script, make sure you have the following installed:

- Node.js
- Yarn

## Installation

To install the necessary dependencies, run the following command in the command line interface:

`yarn`

## Usage

To use the script, follow these steps:

1. Prepare a translation excel file based on the sample translation file in the repository. Save the file in the repository directory.

2. Run the following command in the command line interface:

`node translation.js`

This will run the translation script and output the translated file.
